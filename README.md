# .gdlvl Repository

A collection of well-known **Geometry Dash levels** in `.gdlvl` format.

### How to Import
1. Open Geometry Dash.
2. Navigate to the **My Levels** page and select the in-game **Import** button.
3. Choose the `.gdlvl` file you want to import.

> **Requirements:** Importing `.gdlvl` files is only supported in Geometry Dash version **2.209 and later**.
